# Modern Variants

The Computer Science community didn't stop after Jerome Friedman came up with a different point of view for Boosting. Since then, some variants have been developed in order to make the central idea of the algorithm even more robust.

## XGBoost

XGBoost started as a research project conducted by Tianqi Chen at the Distributed Machine Learning Community (DMLC).
This variant, unlike the Gradient Boosting, which is developed on first-order gradients, leverages a second-order Taylor expansion of the loss function by the Newton-Raphson method. The Newton-Raphson method finds the roots of a differentiable function f, which are the solutions to the equation f(x) = 0, by iteration, through a second-order Taylor expansion. This change provided more accurate and stable optimization.

XGBoost became quite famous in 2014, after being used for a solution at the Higgs Boson Challenge, which consisted in classifying particle collisions to identify the Higgs boson. Since then, it has been present in many Kaggle competitions.

Some of its advantages in comparison to the classic Gradient Boost are:

1. **Speed**
Leverages memory optimization, CPUs and paralelization, handling much bigger datasets than the classic Gradient Boost

2. **Explicit Regularization**
Introduces the L1 (Lasso) and L2 (Ridge) penalizations in the tree leaves, helping prevent overfitting

3. **Sparse data**
Gracefully handles missing values or sparse data (features with many zeros)

4. **Flexibility**
It is suitable for many supervisied learning models, such as Regression, Classification and Ranking

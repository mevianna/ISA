Quase nunca queremos olhar a tabela inteira. Selecionar e filtrar é pegar **só as colunas e linhas que interessam** para uma pergunta.

## 3.1 Seleção de colunas

**Uma coluna:** nome entre colchetes. O resultado é uma **Series**.

```python
df["city"]
```

**Várias colunas:** uma lista de nomes entre colchetes (por isso os colchetes duplos). O resultado é um **DataFrame**.

```python
df[["city", "area", "rooms"]]
```

## 3.2 Seleção de linhas

Para selecionar linhas usamos `loc` e `iloc`, sempre no formato `[linhas, colunas]`.

## 3.3 loc e iloc

| | `loc` | `iloc` |
|---|---|---|
| Seleciona por | **rótulo** (nome do índice e da coluna) | **posição** (número, começando do 0) |
| No intervalo `a:b`, o `b` | **entra** | **não entra** |

```python
df.loc[0]                                     # linha com índice 0
df.loc[0:4, ["city", "rent_amount_(BRL)"]]    # linhas 0 a 4 (5 linhas), 2 colunas
df.iloc[0:5, 0:3]                             # 5 primeiras linhas, 3 primeiras colunas
df.iloc[-1]                                   # última linha
```

**Quando usar cada um:** `loc` quando você sabe o nome (da coluna, do índice); `iloc` quando quer "as primeiras N" ou "a última".

## 3.4 Filtros condicionais

Um filtro seleciona as linhas que obedecem a uma condição. Funciona em dois passos:

1. A condição cria uma lista de Verdadeiro/Falso, uma para cada linha.
2. O `df[...]` mantém só as linhas Verdadeiras.

```python
df["city"] == "Porto Alegre"        # passo 1: True/False para cada linha
df[df["city"] == "Porto Alegre"]    # passo 2: só as linhas True
```

Operadores de comparação: `==` (igual), `!=` (diferente), `>`, `>=`, `<`, `<=`.

```python
df[df["rooms"] >= 3]   # imóveis com 3 quartos ou mais
```

## 3.5 Múltiplas condições

| Operador | Significado |
|---|---|
| `&` | **e** (as duas condições precisam ser verdadeiras) |
| `\|` | **ou** (basta uma ser verdadeira) |
| `~` | **não** (inverte a condição) |

**Cada condição precisa estar entre parênteses.**

```python
# aluguel até R$ 2.000 E aceita animais
df[(df["rent_amount_(BRL)"] <= 2000) & (df["animal"] == "acept")]

# Campinas OU Belo Horizonte
df[(df["city"] == "Campinas") | (df["city"] == "Belo Horizonte")]
```

**Curiosidade:** no dataset, "aceita animais" está escrito `acept`, com um "c" só. O filtro precisa usar exatamente o mesmo texto.

**Filtro + loc:** o filtro escolhe as linhas e a lista escolhe as colunas.

```python
df.loc[df["furniture"] == "furnished", ["city", "area", "rent_amount_(BRL)"]]
```

## Resumo

- `df["col"]` → uma coluna (Series); `df[["a", "b"]]` → várias colunas (DataFrame).
- `loc` → por rótulo; `iloc` → por posição.
- Filtro = condição dentro de `df[...]`; várias condições com `&` e `|`, cada uma entre parênteses.

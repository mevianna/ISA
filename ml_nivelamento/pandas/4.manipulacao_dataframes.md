Manipular é **modificar a tabela** para deixá-la pronta para a análise: mudar nomes, criar e alterar colunas, remover o que não serve, ordenar e resumir.

## 4.1 Renomeação de colunas

`rename()` troca nomes de colunas. Recebe um dicionário `{"nome antigo": "nome novo"}`.

```python
df = df.rename(columns={
    "city": "cidade",
    "rent_amount_(BRL)": "aluguel",
    "hoa_(BRL)": "condominio",
    # ...
})
```

**Por que fazer:** nomes curtos e sem símbolos são mais fáceis de digitar e evitam erros.

**Atenção:** a maioria dos métodos do Pandas **não altera** a tabela original, eles devolvem uma cópia. Por isso escrevemos `df = df.rename(...)`.

## 4.2 Criação de colunas

Basta dar um nome novo e dizer como calcular. A conta é feita em todas as linhas de uma vez.

```python
df["preco_m2"] = df["aluguel"] / df["area"]
```

**No nosso exemplo:** um imóvel grande é naturalmente mais caro, então o **preço por m²** deixa a comparação entre cidades mais justa.

## 4.3 Alteração de colunas

Para mudar os valores de uma coluna existente, atribuímos o novo valor a ela:

```python
df["mobiliado"] = df["mobiliado"].replace({"furnished": "sim", "not furnished": "não"})
df["preco_m2"] = df["preco_m2"].round(2)
```

## 4.4 Remoção de linhas e colunas

`drop()` remove colunas (`columns=`) ou linhas (`index=`).

```python
# remover uma coluna
df = df.drop(columns=["seguro"])

# remover linhas: primeiro encontramos o índice delas, depois passamos para o drop
sem_banheiro = df[df["banheiros"] == 0].index
df = df.drop(index=sem_banheiro)
```

## 4.5 Ordenação de dados

`sort_values()` ordena pela coluna escolhida. Por padrão, do menor para o maior; com `ascending=False`, do maior para o menor.

```python
df.sort_values("aluguel", ascending=False).head()   # 5 aluguéis mais caros
```

## 4.6 Agrupamento com groupby()

`groupby()` separa a tabela em grupos e calcula algo para cada grupo. Funciona em três passos: **separar → calcular → juntar**.

```python
df.groupby("cidade")["aluguel"].mean().sort_values()
```

- `groupby("cidade")` → separa em um grupo por cidade
- `["aluguel"].mean()` → calcula a média do aluguel em cada grupo
- `sort_values()` → ordena o resultado

Com `agg()` dá para calcular várias estatísticas de uma vez:

```python
df.groupby("cidade")["aluguel"].agg(["count", "mean", "min", "max"])
```

**Como aplicar:** o `groupby` responde perguntas do tipo "qual grupo tem o maior valor?", como a pergunta do nosso exemplo: qual cidade tem o aluguel mais caro.

## Resumo

| Comando | Para que serve |
|---|---|
| `rename()` | trocar nomes de colunas |
| `df["nova"] = ...` | criar ou alterar uma coluna |
| `replace()` / `round()` | trocar valores / arredondar |
| `drop()` | remover linhas ou colunas |
| `sort_values()` | ordenar |
| `groupby()` + `mean()` / `agg()` | resumir por grupo |

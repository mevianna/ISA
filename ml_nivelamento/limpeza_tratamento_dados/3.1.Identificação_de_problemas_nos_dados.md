# IDENTIFICAÇÃO DE PROBLEMAS NOS DADOS

A limpeza de dados visa detectar e remover anomalias dos dados com o objectivo
de melhorar a sua qualidade. Visando este objetivo o autores de "Limpeza de dados-uma visão geral" classificam o processo semi-automatico de operações da seguinte 
forma: (1) executa a adaptação de formatos nos tuplos e valores; (2) força as restrições de
integridade; (3) deriva valores em falta a partir dos existentes; (4) remove conflitos
nos tuplos ou entre os tuplos; (5) funde e elimina duplicados; e (6) detecta desvios,
isto é, tuplos e valores com um grande potencial de serem inválidos. [1] 
Os cuidados que devem ser tomados na construção de uma base de dados varia conforme o nível de abstração da linguagem que esta usando. 
Com isso em mente para os exemplos a seguir vou utilizar da linguagem de alto nível, o python. Primeiro é preciso saber identificar o tipo de problema para depois 
tratá-lo, como os exemplos que serão apresentados : valores ausentes, dados duplicados, tipos de dados incorretos, valores inconcistentes. 
Existem bibliotecas em python com ferramentas para manipulação de banco de dados que ajudam a identificar os valores que buscamos. 
Mas é possível encontrar estes valores com python puro. Caso não tratados, os valores nulos podem fazer o programa resultar em um erro crítico ou pior, um 
comportamento inesperado. Estes problemas no melhor dos casos interrompe o código, já em uma situação critica poderia atrasar semanas uma produção por conta de um 
tratamento incorreto de dados. (tuplos: é uma estrutura de dados que armazena uma coleção ordenada de elementos fixos.)

Exemplo de código em python com bibliotecas para identificar valores ausentes:

    import pandas as pd
    import numpy as np
    
    #Dados exemplo com a biblioteca pandas e numpy
    data = {
        'A': [1, 2, np.nan],
        'B': [4, np.nan, np.nan],
        'C': [7, 8, 9]
    }
    df = pd.DataFrame(data)
    
    #Teste para dados nulos
    print(df.isnull())

#saida do código:

    0     False  False  False

    2     True   True   False


Em um caso de dados duplicados, ocupa-se um espaço a mais desnecessário na memória com um valor extra. Assim, dependendo do código e volume de dados as previsões 
da analise serão distorcidas e vão geral resultados falsos, prejudicando a tomada de decisão. Para dados duplicados existem soluções mais simples para evita-las 
com o uso de tipos de dado como dícionários(hashmaps) ou caso não esteja de acordo com o problema, é possível identifica-lo com código.
(dicionários: É uma estrutura de dados que armazena uma coleção de elementos associadas a uma chave única, impedindo repetição.)

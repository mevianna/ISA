# 3.1 IDENTIFICAÇÃO DE PROBLEMAS NOS DADOS

A limpeza de dados visa detectar e remover anomalias dos dados com o objectivo
de melhorar a sua qualidade. Visando este objetivo os autores de "Limpeza de dados-uma visão geral" classificam este como um processo semi-automatico regido em 
operações da seguinte 
forma: (1) executa a adaptação de formatos nos tuplos e valores; (2) força as restrições de
integridade; (3) deriva valores em falta a partir dos existentes; (4) remove conflitos
nos tuplos ou entre os tuplos; (5) funde e elimina duplicados; e (6) detecta desvios,
isto é, tuplos e valores com um grande potencial de serem inválidos. [1]
(tuplos: é uma estrutura de dados que armazena uma coleção ordenada de elementos fixos. Diferente de uma lista com elementos mutáveis)

Os cuidados que devem ser tomados na construção de uma base de dados varia conforme o nível de abstração da linguagem que esta usando. 
Com isso em mente para os exemplos a seguir vou utilizar da linguagem de alto nível, o python. Primeiro é preciso saber identificar o tipo de problema para depois 
tratá-lo, como os exemplos que serão apresentados : valores ausentes, dados duplicados, tipos de dados incorretos, valores inconcistentes. 
Existem bibliotecas em python com ferramentas para manipulação de banco de dados que ajudam a identificar os valores que buscamos. 
Mas é possível encontrar estes valores com python puro. Caso não tratados, os valores nulos podem fazer o programa resultar em um erro crítico ou pior, um 
comportamento inesperado. Estes problemas no melhor dos casos interrompe o código, já em uma situação critica poderia atrasar semanas uma produção por conta de um 
tratamento incorreto de dados. (Observação, o artigo fala em tuplos, mas as analises podem ser feitas em vetores mutaveis também)

Exemplo de código em python puro para identificar valores ausentes:

    #lista de dados simples

    vendas = [150.0, 200.0, None, 120.0, None, 300.0]

    posicoes_ausentes = [ ] #lista vazia
    for indice, valor in enumerate(vendas):
      if valor is None:
        posicoes_ausentes.append(indice)

    print(f"Posições com valores ausentes na lista: {posicoes_ausentes}")

Saida do código:

    Posições com valores ausentes na lista: [2, 4]

Exemplo de código em python com bibliotecas para identificar valores ausentes:

    import pandas as pd
    import numpy as np
    
    #Dados exemplo com a biblioteca pandas e numpy
    data = {

    }

Saida do código:

Em um caso de dados duplicados, ocupa-se um espaço a mais desnecessário na memória com um valor extra. Assim, dependendo do código e volume de dados as previsões 
da analise serão distorcidas e vão geral resultados falsos, prejudicando a tomada de decisão. Para dados duplicados existem soluções mais simples para evita-las 
com o uso de tipos de dado como dícionários(hashmaps) ou caso não esteja de acordo com o problema, é possível identifica-lo com código.
(dicionários: É uma estrutura de dados que armazena uma coleção de elementos associadas a uma chave única, impedindo repetição.)

Exemplo de código em python puro para identificar valores duplicados:

    # lista de dados simples
    vendas = [150.0, 200.0, 120.0, 150.0, 300.0, 200.0]
    
    posicoes_duplicadas = []  # lista vazia
    vistos = set()            # conjunto para armazenar valores únicos já vistos
    
    for indice, valor in enumerate(vendas):
        if valor in vistos:
            posicoes_duplicadas.append(indice)
        else:
            vistos.add(valor)

    print(f"Posições com valores duplicados na lista: {posicoes_duplicadas}")

Saída do código:

    Posições com valores duplicados na lista: [3, 5]
    

Exemplo de código em python com bibliotecas para identificar valores duplicados:

    import pandas as pd
    import numpy as np
    
    # Dados exemplo com a biblioteca pandas e numpy
    data = {
        'A': [1, 2, 2, 3, 4],
        'B': [4, 5, 5, 6, 1],
        'C': [7, 8, 8, 9, 9]
    }
    df = pd.DataFrame(data)
    
    # Teste para dados duplicados na linha(índices)
    print(df.duplicated())
    
    # Teste para dados duplicados nas colunas(Elementos:'A','B','C')
    print(df.duplicated(subset=['A']))
    print(df.duplicated(subset=['B']))
    print(df.duplicated(subset=['C']))

A tipagem dos dados deve estar de acordo com o seu papel na analise ou funcionalidade do processo. Dados errados com o processo não necessariamente acusam erro, 
mas podem prejudicar a analise. Um exemplo disso é no meio de um processo, por um descuido na lógica, um valor "float" se tornar "int", reduzindo a precisão da 
analise. Para garantir que o valor esteja no formato correto existem comandos nativos do Python, como type() e isinstance() escrito da seguinte forma:

Exemplo simples da função type e isistance:

    string = "Olá mundo"
    inteiro = 3
    racional = 3.14159265
    booleano = True
    lista = [1, 2, 3]
    dicionario = {"nome": "Ana", "idade": 25}
    nulo = None
    
    print("Tipo da variável string:", type(string))
    print("Tipo da variável inteiro:", type(inteiro))
    print("Tipo da variável racional:", type(racional))
    print("Tipo da variável booleano:", type(booleano))
    print("Tipo da variável lista:", type(lista))
    print("Tipo da variável dicionario:", type(dicionario))
    print("Tipo da variável nulo:", type(nulo))
    
    print("string é str?", isinstance(string, str))
    print("inteiro é int?", isinstance(inteiro, int))
    print("racional é float?", isinstance(racional, float))
    print("booleano é bool?", isinstance(booleano, bool))
    print("lista é list?", isinstance(lista, list))
    print("dicionario é dict?", isinstance(dicionario, dict))
    print("nulo é NoneType?", isinstance(nulo, type(None)))

Exemplo simples analisando uma lista:

    # lista de dados simples
    vendas = [150.0, 200.0, "N/A", 120.0, True, 300.0]
    
    tipos = []  # lista
    busca_float = [] 
    for valor in vendas:
        tipos.append(type(valor))
        busca_float.append(isinstance(valor, float))
    
    print(f"Tipos dos elementos da lista: {tipos}")
    
    print(f"Quais são float na lista: {busca_float}")

Saída do código:

    Tipos dos elementos da lista: [<class 'float'>, <class 'float'>, <class 'str'>, <class 'float'>, <class 'bool'>, <class 'float'>]
    Quais são float na lista: [True, True, False, True, False, True]
    
Exemplo de analise de tipo com pandas:

    import pandas as pd

    # Dados guardados 
    data = {
        'Nome': ['Ana', 'Bruno', 'Carlos'],
        'Serviço': ['Encanadora', 45, 'Carpinteiro'],   # int 45 no meio de strings
        'Idade': [25, 32, 45],
        'Salario': [50000.0, 65000, 75000.0],           # int 65000 no meio de floats
        'Empregado': [True, True, False]
    }
    
    # Criar DataFrame impedindo que a biblioteca tente adivinhar os valores
    df = pd.DataFrame(data, dtype=object)
    
    # Definir o tipo esperados para a comparação
    tipos_esperados = {
        'Nome': str,
        'Serviço': str,
        'Idade': int,
        'Salario': float,
        'Empregado': bool
    }
    
    print("DataFrame original (tipos preservados):")
    print(df)
    print("\nTipos das colunas (forçado object):")
    print(df.dtypes)
    print("-" * 60)
    
    # Verificar cada coluna
    for coluna in df.columns:
        tipo_esperado = tipos_esperados[coluna]
        print(f"\nColuna '{coluna}' — tipo esperado: {tipo_esperado}")
    
    for indice, valor in df[coluna].items():
        if not isinstance(valor, tipo_esperado):
            print(f"Linha {indice}: valor = {valor!r} | tipo encontrado = {type(valor)}") #!r deixa a variavel destacada: 'variavel'

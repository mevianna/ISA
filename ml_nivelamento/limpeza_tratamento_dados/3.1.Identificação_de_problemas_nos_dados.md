# IDENTIFICAÇÃO DE PROBLEMAS NOS DADOS

Os cuidados que devem ser tomados na construção de uma base de dados varia conforme o nível de abstração da linguagem que esta usando. 
Com isso em mente para os exemplos a seguir vou utilizar da linguagem de alto nível, o python. Primeiro é preciso saber identificar o tipo de problema para depois tratá-lo,
por exemplo com valores ausentes, dados duplicados, tipos de dados incorretos, valores inconcistentes.

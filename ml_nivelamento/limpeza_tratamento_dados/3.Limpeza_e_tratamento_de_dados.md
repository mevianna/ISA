# 3 INTRODUÇÃO
     
A importância da higienização de dados se deve ao fato de que: A qualidade dos dados que deseja-se trabalhar interfere de forma direta no 
resultado do seu processo. Isto vale para os mais diversos propósitos, como machine learning, analises qualitativas em pesquisas, controle 
digital de embarcados ou até mesmo uma simples avaliação de um grande volume de dados.[1] A fim de conseguir uma base de dados limpa é 
possível focar em problemas comuns e seus metodos de solução, que serão abordados nos próximos tópicos.

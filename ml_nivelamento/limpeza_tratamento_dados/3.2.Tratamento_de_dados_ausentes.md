# 3.2 Tratamento de dados ausentes

Após identificar o problema de dados ausentes descrito no módulo anterior(3.1) é preciso tratar estes dados de acordo com a aplicação.
É importante ressaltar que somente apagá-los ou os ignorar não necessariamente resolve o problema e pode acabar causando outros. Por isso, deve-se entender como 
identificar quando usar o preenchimento do dados e quando remove-los. Para quando o volume de dados nulos ocupa até 5% dos valores, apaga-los não afetará tanto o resultado da analise. Mas quando ocupa mais que 5%, a perda destes dados leva a uma significante perda de informações, fazendo o método de imputação(preenchimento) mais apropriado.[2]

# 3.2 Tratamento de dados ausentes

Após identificar o problema de dados ausentes descrito no módulo anterior(3.1) é preciso tratar estes dados de acordo com a aplicação.
É importante ressaltar que somente apagá-los ou os ignorar não necessariamente resolve o problema e pode acabar causando outros. Por isso, deve-se entender como 
identificar quando usar o preenchimento do dados e quando remove-los. Considerando que a remoção de dados ocorra por linha com elementos faltantes: Para quando o 
volume de dados a ser apagados ocupa até 5% dos valores, apagá-los não afetará tanto o resultado da analise. Mas quando ocupa mais que 5%, a perda destes dados leva 
a uma significante perda de informações, fazendo o método de imputação(preenchimento) mais apropriado.[2]  

Para remover os valores ausentes é possível usar o método de identificação do modulo anterior, tanto com o Python quanto para o Pandas. E com isso remover as linhas de código que não interessam para o processo, caso não afete muito o resultado final. 

Exemplo com só com python:


Exemplo com a biblioteca pandas com a função dropna(), por exemplo:

    import pandas as pd
    import numpy as np
    
    data = {
        'A': [1, 2, np.nan, 22, 5],
        'B': [4, np.nan, 7, 13, 9],
        'C': [7, 8, 9, 10, 32],
        'D': [np.nan,np.nan,np.nan,np.nan,np.nan],
        'E': [np.nan, 12, np.nan, 27, 25]
    }
    df = pd.DataFrame(data)
    
    print("DataFrame original:")
    print(df)
    
    
    df_limpo_linha = df.dropna()
    df_limpo_coluna = df.dropna(axis=1)
    df_linhas_vazias = df.dropna(how='all')
    df_ate_tres_validos = df.dropna(thresh=3)
    
    print("DataFrame sem linhas com valores ausentes:")
    print(df_limpo_linha)
    print("\n")
    print("DataFrame sem colunas com valores ausentes:")
    print(df_limpo_coluna)
    print("\n")
    print("DataFrame sem linhas com só valores ausentes:")
    print(df_linhas_vazias)
    print("\n")
    print("DataFrame sem linhas com mais que três valores ausentes:")
    print(df_ate_tres_validos)

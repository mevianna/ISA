# 3.2 Tratamento de dados ausentes

Após identificar o problema de dados ausentes descrito no módulo anterior(3.1) é preciso tratar estes dados de acordo com a aplicação.
É importante ressaltar que somente apagá-los ou os ignorar não necessariamente resolve o problema e pode acabar causando outros. Por isso, deve-se entender como 
identificar quando usar o preenchimento do dados e quando remove-los. Considerando que a remoção de dados ocorra por linha com elementos faltantes: Para quando o 
volume de dados a ser apagados ocupa até 5% dos valores, apagá-los não afetará tanto o resultado da analise. Mas quando ocupa mais que 5%, a perda destes dados 
leva a uma significante perda de informações, fazendo o método de imputação(preenchimento) mais apropriado.[2]  

Para remover os valores ausentes é possível usar o método de identificação do modulo anterior, tanto com o Python quanto para o Pandas. E com isso remover as 
linhas de código que não interessam para o processo, caso não afete muito o resultado final. 

Exemplo simples de varredura só com python:

    tabela = [
    {'A': 1,    'B': 4,    'C': 7},
    {'A': 2,    'B': None, 'C': 8},
    {'A': None, 'B': 7,    'C': 5},
    {'A': 12,   'B': 7,    'C': 9}
    ]

    limpeza_linhas = []
    for linha in tabela:
        if None not in linha.values():
            limpeza_linhas.append(linha)
            
    print(limpeza_linhas)
    
Saída do código:
    
    [{'A': 1, 'B': 4, 'C': 7}, {'A': 12, 'B': 7, 'C': 9}]

Exemplo com a biblioteca pandas com a função dropna():

    import pandas as pd
    import numpy as np
    
    data = {
        'A': [1, 2, np.nan, 22, 5],
        'B': [4, np.nan, 7, 13, 9],
        'C': [7, 8, 9, 10, 32],
        'D': [np.nan,np.nan,np.nan,np.nan,np.nan],
        'E': [np.nan, 12, np.nan, 27, 25]
    }
    df = pd.DataFrame(data)
    
    print("DataFrame original:")
    print(df)
    
    
    df_limpo_linha = df.dropna()
    df_limpo_coluna = df.dropna(axis=1)
    df_linhas_vazias = df.dropna(how='all')
    df_ate_tres_validos = df.dropna(thresh=3)
    
    print("\nDataFrame sem linhas com valores ausentes:")
    print(df_limpo_linha)
    print("\n")
    print("DataFrame sem colunas com valores ausentes:")
    print(df_limpo_coluna)
    print("\n")
    print("DataFrame sem linhas com só valores ausentes:")
    print(df_linhas_vazias)
    print("\n")
    print("DataFrame sem linhas com mais que três valores ausentes:")
    print(df_ate_tres_validos)

Como demostrado nos exemplos acima, mesmo que muitos valores ausentes se encontrem em uma base de dados, haviam linhas e colunas que ainda poderiam ser 
aproveitadas e foram removidas por inteiro sem necessidade. O percentual de dados aproveitados, caso haja somente alguns valores ausentes, pode ser maior. Para 
isso deve-se considerar apagar linhas e colunas com muitos valores faltantes, de forma que não enviese o resultado. Dessa forma, o método mais adequado para 
lidar com números ausentes depende do quanto será alterado o resultado final. A fim de resolver o problema de valores não disponíveis com a imputação temos os 
seguintes exemplos:

Exemplo com a biblioteca pandas com a função fillna():
    
    import pandas as pd
    import numpy as np
    
    data = {
            'A': [1, 2, np.nan, 22, 5],
            'B': [4, np.nan, 7, 13, 9],
            'C': [7, 8, 9, 10, 32],
            'D': [4,6,9,np.nan,np.nan],
            'E': [3, 12, np.nan, 27, 25]
        }
    df = pd.DataFrame(data)

    preenchimento_zero = df.fillna(0)

Por mais que preencher com zero tire os valores ausentes, ele também vai interferir no resultado. Existem outros métodos de preenchimento também com a biblioteca 
pandas, como ffill(), que preenche com o valor da linha anterior. Além deste método há a função bfill(), que ao contrario de ffill(), preenche com o dado 
posterior. Entretanto estes métodos são limitado ao numero que vão comparar não ser ausente. Para evitar isso podemos combinar as funções como no exemplo a seguir:

Exemplo com a biblioteca pandas com funções ffill() e bfill:

    import pandas as pd
    import numpy as np
        
    data = {
            'A': [1, 2, np.nan, 22, 5],
            'B': [np.nan, np.nan, 7, 13, 9],
            'C': [7, 8, 9, 10, 32],
            'D': [4,6,9,np.nan,np.nan],
            'E': [3, 12, np.nan, 27, 25]
        }
    df = pd.DataFrame(data)
    
    
    preenchimento_anterior = df.ffill()
    
    preenchimento_posterior = df.bfill()
    
    preenchimento_combinado = df.ffill().bfill()
    
    print("Antes da modificação:")
    print(df)
    print("\n Após modificado, respectivamente")
    print(preenchimento_anterior)
    print("\n")
    print(preenchimento_posterior)
    print("\n")
    print(preenchimento_combinado)
